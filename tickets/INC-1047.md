# INC-1047: Active Directory Expired Account Remediation & Extension

---

## Incident Overview
* **Incident ID:** INC-1047
* **Date / Time:** 2026-08-11
* **Category:** Helpdesk Support / Active Directory User Management
* **Severity:** Low (Contractor Access Renewal)
* **Status:** Resolved / Documented

---

## Issue Description
User `aramos` (Contractor) reported being unable to authenticate into the domain, presenting an explicit error message stating that their user account has expired.

---

## Diagnostics & Investigation
1. **Directory Inspection:** Accessed Active Directory Users and Computers (ADUC) on the domain controller and opened the properties for user `aramos`.
2. **Attribute Verification:** Navigated to the Account tab and confirmed that the account expiration attribute was set to a past date, resulting in automated access denial.
3. **Administrative Validation:** Verified contract extension details with department management to authorize account renewal.

---

## Remediation & Resolution
1. **Attribute Modification:** Updated the account expiration settings in ADUC from the expired date to a new authorized timeline.
2. **Access Restoration:** Applied changes and verified that the user was immediately able to successfully re-authenticate to the domain.
